## จุดที่ยังอ่อน

### 1. Mixed Conditionals Type 1 vs Type 2 (ผิด 2/10)

| Type | โครงสร้าง | Signal |
|------|-----------|--------|
| Type 1 (อดีต→ปัจจุบัน) | `If + Past Perfect, would + V` | time อดีต (ago) + result มี "now/today" |
| Type 2 (ปัจจุบัน→อดีต) | `If + were/Simple Past, would have + V3` | if-clause = สถานะปัจจุบัน, result = อดีต |

กลยุทธ์: **ดู result clause ก่อน** — ถ้า `would have + V3` = result อดีต → if-clause ต้องเป็น `were` (ปัจจุบัน)

### 2. Were ทุก Subject (ผิด 1/10)

ใน TOEIC formal writing ใช้ `were` กับทุก subject เสมอใน:
- Second Conditional: `If she **were** more experienced…`
- Wish: `I wish the project **were** simpler.`
- If Only: `If only the budget **were** larger.`

### 3. Present Perfect vs Present Continuous (Part 6 ผิด 1/4)

- `have introduced` = เสร็จแล้ว ผลยังอยู่ (portal พร้อมใช้งาน) ✅
- `are introducing` = ยังอยู่ระหว่างดำเนินการ (ขัดกับ "clients must use" ตั้งแต่ June 1)

### 4. Conjunction: in case vs as long as

- `in case` = เผื่อว่า (เตรียมรับมือสิ่งที่อาจเกิด)
- `as long as` = ตราบใดที่ (เงื่อนไขต่อเนื่องที่ต้องคงอยู่)
