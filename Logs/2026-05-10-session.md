## จุดที่ยังอ่อน

### 1. so...that vs such...that (Part 5, Q7)

ตอบ A (so / that) แต่ถูกคือ B (such / that)

| โครงสร้าง | ตามด้วย | ตัวอย่าง |
|:---------|:--------|:---------|
| **so + adj + that** | adjective เท่านั้น (ไม่มี noun) | The project was **so complex that** it required a specialist. |
| **such + a/an + (adj) + noun + that** | noun phrase | It was **such a productive workshop that** we held a follow-up. |

> เคล็ดลับ: ถ้าเห็น noun อยู่ใน clause → ต้องใช้ **such** เสมอ

### 2. Part 7 — Inference Questions (Q3, Q4, Q5)

ผิดทั้ง 3 ข้อที่เป็น non-factual → pattern ที่ชัดเจนว่าอ่อน

**Q3 Inference:** ตอบ C แต่ถูกคือ B
- C ดูสมเหตุสมผลแต่ไม่มี evidence ใน passage
- B infer ได้จาก "mitigate disruptions caused by **single-source dependencies**" → ปัจจุบันมี single supplier จริง
- กฎ: inference ต้องมี **keyword ใน passage** ค้ำยันเสมอ

**Q4 NOT stated:** ตอบ C แต่ถูกคือ B
- C ("suspension until requirement is fulfilled") เขียนไว้ชัดใน passage → ไม่ใช่คำตอบ
- B ("formal written warning") ไม่มีอยู่ใน passage เลย → คือคำตอบ
- กฎ: NOT stated = หาข้อที่ **ไม่มีหลักฐานใน passage** ไม่ใช่ข้อที่ฟังดู "ไม่น่าจะจริง"

**Q5 Implied detail:** ตอบ D แต่ถูกคือ C
- D ขัดแย้งโดยตรง: passage บอกว่า Phase 2/3 จะ communicate หลัง Phase 1 submissions
- C มาจาก "assist managers with the submission process" → implied ว่าจะอธิบายวิธีส่ง
- กฎ: distractors มักนำ keyword จริงมาบิดเนื้อหา — ต้องย้อนกลับ verify กับ passage เสมอ
