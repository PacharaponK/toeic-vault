# 05 — Articles

## A vs AN — กฎเสียง (ไม่ใช่ตัวอักษร)

ใช้ **a** ก่อนเสียงพยัญชนะ / ใช้ **an** ก่อนเสียงสระ

| ตัวอย่าง | เหตุผล |
|----------|--------|
| **a** university | /juː/ เริ่มต้นด้วยเสียง /j/ (พยัญชนะ) |
| **an** hour | /ˈaʊər/ เริ่มต้นด้วยเสียง /aʊ/ (สระ — h เงียบ) |
| **a** one-way street | /wʌn/ เริ่มต้นด้วยเสียง /w/ (พยัญชนะ) |
| **an** honest person | /ˈɒnɪst/ เริ่มต้นด้วยเสียง /ɒ/ (สระ) |
| **an** MBA degree | /ɛm/ เริ่มต้นด้วยเสียง /ɛ/ (สระ) |
| **a** European country | /jʊərəˈpiːən/ เริ่มต้นด้วยเสียง /j/ (พยัญชนะ) |

---

## A / AN — การใช้งาน

- สิ่งที่กล่าวถึงเป็นครั้งแรก → **a/an** new employee joined the team.
- หมวดหมู่ทั่วไป (generic) → **A** manager should listen to staff.
- อาชีพ/ตำแหน่ง → She is **a** project coordinator.
- ตัวเลข → **a** hundred / **a** dozen / **a** few

---

## THE — กฎ 5 ข้อ

| กฎ | ตัวอย่าง |
|----|---------|
| **1.** กล่าวถึงซ้ำ (second mention) | We hired **a** consultant. **The** consultant started Monday. |
| **2.** มีแค่อันเดียวในโลก (unique) | **the** sun, **the** moon, **the** internet, **the** president |
| **3.** ระบุชัดเจน (superlative / ordinal) | **the** best / **the** first quarter / **the** most efficient |
| **4.** ชื่อเฉพาะบางประเภท | **the** United States, **the** Amazon, **the** BBC |
| **5.** ผู้ฟังรู้ว่าหมายถึงอะไร (shared knowledge) | Please close **the** door. (ประตูที่เราเห็นอยู่) |

---

## Zero Article — ไม่ใส่ Article

| หมวด | ตัวอย่าง |
|------|---------|
| Proper nouns (ทั่วไป) | ~~the~~ Thailand, ~~the~~ John Smith, ~~the~~ Wall Street |
| Abstract nouns | ~~the~~ information, ~~the~~ advice, ~~the~~ knowledge |
| Meals | at ~~the~~ lunch, after ~~the~~ breakfast, before ~~the~~ dinner |
| Academic subjects | study ~~the~~ economics, major in ~~the~~ finance |
| Languages | speak ~~the~~ English, learn ~~the~~ Japanese |
| Means of transport (by) | by ~~the~~ train, by ~~the~~ air, by ~~the~~ car |
| Plural countable (generic) | ~~The~~ Employees need motivation. |

## Countable vs Uncountable Nouns

### Uncountable ที่มักสับสนใน TOEIC
| ผิด            | ถูก                                               |
| -------------- | ------------------------------------------------- |
| an information | **some information** / **a piece of information** |
| a news         | **some news** / **a piece of news**               |
| an advice      | **some advice** / **a piece of advice**           |
| a luggage      | **a piece of luggage** / **luggage**              |
| a research     | **research** / **a study**                        |
| a work         | **work** / **a job** / **a task**                 |
| furnitures     | **furniture**                                     |
| equipments     | **equipment**                                     |

## Articles ใน Business English Context

| สถานการณ์             | ตัวอย่าง                                                     |
| --------------------- | ------------------------------------------------------------ |
| ตำแหน่งงาน (specific) | She was appointed **the** CEO of the company.                |
| ตำแหน่งงาน (generic)  | **A** good manager delegates effectively.                    |
| ชื่อบริษัท            | ~~the~~ Google, ~~the~~ Toyota (แต่ **the** BBC, **the** UN) |
| แผนกในบริษัท          | in **the** marketing department / from **the** HR team       |
| ผลิตภัณฑ์เฉพาะ        | **the** iPhone, **the** Model S                              |
| ความคิดรวบยอด         | **The** customer is always right.                            |

## Common Mistakes ใน TOEIC

| ผิด                                   | ถูก                                       | เหตุผล                                  |
| ------------------------------------- | ----------------------------------------- | --------------------------------------- |
| She is **the** manager of HR.         | She is **a** manager of HR.               | ถ้ามีหลายคนในตำแหน่งนั้น                |
| I need **an** information.            | I need **some** information.              | information ไม่นับได้                   |
| The report is on **a** Table 3.       | The report is on **~~a~~** Table 3.       | ตาราง/หน้าที่ระบุหมายเลข → zero article |
| He has **a** MBA.                     | He has **an** MBA.                        | /ɛm/ เสียงสระ                           |
| The company is in **the** bankruptcy. | The company is in **~~the~~** bankruptcy. | abstract state → zero article           |

## ตัวอย่างประโยค TOEIC Part 5 Style (6 ข้อ)

1. _______ annual performance review will be conducted next month.
   **(A) A (B) An (C) The (D) —**
   → **C** (ทุกคนรู้ว่าหมายถึงการประเมินที่กำลังจะมาถึง = shared knowledge)

2. Mr. Park submitted _______ proposal that exceeded all expectations.
   **(A) a (B) an (C) the (D) —**
   → **A** (กล่าวถึง proposal ครั้งแรก + เสียง /p/ = a)

3. The committee reached _______ agreement after several hours of negotiation.
   **(A) a (B) an (C) the (D) —**
   → **A** (agreement นับได้ในบริบทนี้ = หนึ่งข้อตกลง)

4. _______ feedback from customers has been overwhelmingly positive.
   **(A) A (B) An (C) The (D) —**
   → **C** (feedback ที่ระบุชัด = จากลูกค้าเฉพาะกลุ่มนี้)

5. She has _______ extensive experience in supply chain management.
   **(A) a (B) an (C) the (D) —**
   → **D** (experience = uncountable abstract noun → zero article)

6. Please refer to _______ Appendix B for details.
   **(A) a (B) an (C) the (D) —**
   → **D** (ชื่อเฉพาะ Appendix B → zero article)
