# 14 — Word Forms

## กลยุทธ์การระบุ Word Form

1. ดูว่า blank อยู่ในตำแหน่งอะไรใน sentence
2. ถ้าอยู่หลัง article (a/an/the) หรือ adjective → **Noun**
3. ถ้าอยู่หลัง subject / be verb → **Adjective** หรือ **Noun**
4. ถ้าขยาย verb, adjective, หรือ adverb อื่น → **Adverb**
5. ถ้าเป็น predicate หรือหลัง modal → **Verb**

---

## Noun Suffixes

| Suffix | ความหมาย | ตัวอย่าง |
|--------|----------|---------|
| **-tion / -sion** | การกระทำ / สภาพ | information, decision, production |
| **-ment** | ผล / กระบวนการ | management, agreement, improvement |
| **-ance / -ence** | สภาพ / คุณสมบัติ | performance, difference, compliance |
| **-ity / -ty** | สภาพ / คุณภาพ | quality, productivity, responsibility |
| **-ness** | สภาพ | effectiveness, awareness, timeliness |
| **-er / -or** | ผู้กระทำ | manager, director, supervisor |
| **-ist** | ผู้เชี่ยวชาญ | specialist, economist, analyst |
| **-ship** | สถานะ / ความสัมพันธ์ | leadership, partnership, membership |

## Verb Suffixes

| Suffix | ตัวอย่าง |
|--------|---------|
| **-ize / -ise** | organize, prioritize, maximize, standardize |
| **-ify** | clarify, simplify, qualify, diversify |
| **-en** | strengthen, broaden, shorten, widen |
| **-ate** | evaluate, communicate, coordinate, facilitate |

## Adjective Suffixes

| Suffix | ตัวอย่าง |
|--------|---------|
| **-ful** | successful, careful, meaningful, powerful |
| **-less** | careless, effortless, wireless, meaningless |
| **-ous** | various, ambitious, cautious, numerous |
| **-ive** | effective, productive, competitive, comprehensive |
| **-al** | financial, professional, operational, annual |
| **-ent / -ant** | efficient, significant, relevant, dependent |
| **-able / -ible** | available, reliable, flexible, responsible |
| **-ic** | specific, strategic, economic, systematic |

---

## Adverb Suffix: -ly

> Adj + -ly = Adverb
> effective → **effectively** / significant → **significantly**
> efficient → **efficiently** / final → **finally**

### Irregular adverbs
- good → **well**
- fast → **fast** (ไม่ใช่ fastly)
- hard → **hard** (hardly = แทบจะไม่)
- late → **late** (lately = เร็วๆ นี้)

## กลยุทธ์การจำ Word Forms

### 1. กลุ่ม -tion (noun) / -tive (adj) / -tively (adv)
> produce → product → **productive** → **productively**

### 2. คู่ adj ที่มักสับสน
| คู่สับสน | ความแตกต่าง |
|---------|------------|
| economic / economical | economic = เกี่ยวกับเศรษฐกิจ / economical = ประหยัด |
| respective / respectful | respective = แต่ละ / respectful = มีความเคารพ |
| successful / successive | successful = ประสบความสำเร็จ / successive = ต่อเนื่อง |
| considerable / considerate | considerable = มาก / considerate = เอาใจใส่ผู้อื่น |
| industrial / industrious | industrial = เกี่ยวกับอุตสาหกรรม / industrious = ขยัน |
| confident / confidential | confident = มั่นใจ / confidential = ลับ |
| comprehensive / comprehensible | comprehensive = ครอบคลุม / comprehensible = เข้าใจได้ |
| applicable / applied | applicable = ที่ใช้บังคับได้ / applied = ประยุกต์ใช้ |
| alternate / alternative | alternate = สลับกัน / alternative = ทางเลือกอื่น |
| responsible / responsive | responsible = รับผิดชอบ / responsive = ตอบสนองเร็ว |

### 3. คู่ Noun ที่มักสับสน
| คู่สับสน | ความแตกต่าง |
|---------|------------|
| affect / effect | affect (V) = ส่งผลต่อ / effect (N) = ผลลัพธ์ |
| advice / advise | advice (N) = คำแนะนำ / advise (V) = แนะนำ |
| rise / raise | rise (V) = เพิ่มขึ้นเอง / raise (V) = ทำให้เพิ่มขึ้น |
| affect / effect (ใน business context) | The merger will **affect** operations. / The **effect** of the merger is... |
| practice / practise | practice (N) = การฝึก / practise (V British) = ฝึกปฏิบัติ |
| principal / principle | principal = หลัก/ผู้อำนวยการ / principle = หลักการ |
| personnel / personal | personnel = บุคลากร / personal = ส่วนตัว |
| complement / compliment | complement = ส่วนเสริม / compliment = คำชม |

## ตัวอย่างประโยค TOEIC Part 5 Style (6 ข้อ)

1. The board praised the marketing team for its _______ in developing the new campaign.
   **(A) create (B) creative (C) creativity (D) creatively**
   → **C** (หลัง possessive "its" → noun)

2. The company needs to _______ its supply chain to remain competitive.
   **(A) strength (B) strong (C) strengthen (D) strongly**
   → **C** (ต้องการ verb; strengthen = verb จาก strong)

3. All applicants must submit _______ documentation before the deadline.
   **(A) verify (B) verified (C) verification (D) verifiably**
   → **B** (ขยาย noun "documentation" → adjective)

4. The new system operates _______, reducing processing time by 40%.
   **(A) efficiency (B) efficient (C) efficiently (D) more efficient**
   → **C** (ขยาย verb "operates" → adverb)

5. Ms. Yamamoto is _______ for overseeing all international partnerships.
   **(A) responsible (B) responsibility (C) respond (D) responsibly**
   → **A** (หลัง be verb → adjective; responsible for)

6. The quarterly results showed a _______ improvement in customer satisfaction.
   **(A) signify (B) significant (C) significantly (D) significance**
   → **B** (ขยาย noun "improvement" → adjective)
