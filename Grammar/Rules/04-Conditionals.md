# 04 — Conditionals

## โครงสร้าง Conditional ทั้ง 4 ประเภท

### Zero Conditional — ความจริงสากล / กฎทั่วไป
**If + Simple Present, Simple Present**
> If you heat water to 100°C, it **boils**.
> If the system **detects** an error, it **sends** an alert automatically.

### First Conditional — ความเป็นไปได้จริงในอนาคต
**If + Simple Present, will + V base**
> If the proposal **is approved**, we **will begin** production next month.
> If sales **exceed** the target, bonuses **will be issued**.

### Second Conditional — สมมติสิ่งที่ไม่น่าเป็นจริง / ตรงข้ามปัจจุบัน
**If + Simple Past, would + V base**
> If the company **had** more capital, it **would expand** overseas.
> If I **were** the manager, I **would restructure** the department.
> (ใช้ **were** สำหรับทุก subject ใน formal writing)

### Third Conditional — สมมติสิ่งที่ไม่ได้เกิดขึ้นในอดีต
**If + Past Perfect, would have + V3**
> If the team **had submitted** the report on time, the client **would have renewed** the contract.
> If we **had known** about the issue earlier, we **would have resolved** it immediately.

---

## Mixed Conditionals

### Type 1: Third + Second (อดีต → ปัจจุบัน)
ถ้าอดีตต่างออกไป → ผลในปัจจุบันจะต่างออกไป
**If + Past Perfect, would + V base**
> If she **had taken** the job offer, she **would be** living in New York now.

### Type 2: Second + Third (ปัจจุบัน → อดีต)
ถ้าปัจจุบันเป็นอีกแบบ → ผลในอดีตจะต่างออกไป
**If + Simple Past, would have + V3**
> If he **were** more detail-oriented, he **would have caught** the error in the report.

## Conditional Conjunctions อื่นๆ

| คำ | ความหมาย | ตัวอย่าง |
|----|---------|---------|
| **unless** | if...not (ยกเว้นว่า) | Unless you register by Friday, you won't receive a seat. |
| **provided (that)** | on condition that (โดยมีเงื่อนไขว่า) | Provided that all documents are submitted, approval is guaranteed. |
| **as long as** | if and only if (ตราบใดที่) | You may work remotely as long as you meet all deadlines. |
| **in case** | to prepare for a possibility (เผื่อว่า) | Keep a backup copy in case the system crashes. |
| **only if** | เน้นเงื่อนไขเดียว | Only if the CEO approves can we proceed. |
| **even if** | ถึงแม้ว่า (เงื่อนไขไม่เปลี่ยนผล) | Even if it rains, the event will not be cancelled. |

## Inverted Conditionals (Formal/Business English)

ใน formal writing สามารถละ "if" แล้วกลับโครงสร้างประโยคได้

| Normal | Inverted |
|--------|----------|
| If you **should** need assistance… | **Should** you need assistance… |
| If I **were** in your position… | **Were** I in your position… |
| If they **had** arrived earlier… | **Had** they arrived earlier… |

> **Should** you require further information, please do not hesitate to contact us.
> **Were** the board to approve the merger, the company would double in size.
> **Had** the inspection been completed earlier, the delay could have been avoided.

## ตาราง Common Mistakes ใน TOEIC

| ผิด | ถูก | เหตุผล |
|-----|-----|--------|
| If he **will come**, call me. | If he **comes**, call me. | If-clause ใช้ Simple Present ไม่ใช่ will |
| If I **would be** you, I'd resign. | If I **were** you, I'd resign. | Second conditional ใช้ Past Simple/were |
| If they **would have** told us, we'd have helped. | If they **had** told us, we'd have helped. | If-clause ของ Third conditional ใช้ Past Perfect ไม่ใช่ would have |
| Unless you **don't** register... | Unless you **register**... | unless = if not → ไม่ใช้ not ซ้ำ |

## ตัวอย่าง TOEIC Part 5 Style (5 ข้อ)

1. If the supplier _______ to deliver the materials on time, the project will be delayed.
   **(A) would fail (B) failed (C) fails (D) will fail**
   → **C** (First conditional: if + Simple Present)

2. The project would have been completed on time if the contractor _______ the revised schedule.
   **(A) followed (B) had followed (C) would follow (D) has followed**
   → **B** (Third conditional: if + Past Perfect)

3. _______ you require a receipt, please retain this document for your records.
   **(A) Unless (B) Should (C) Had (D) Provided**
   → **B** (Inverted conditional: Should you require = If you should require)

4. The new policy will take effect next month, _______ it receives final approval from the board.
   **(A) unless (B) provided that (C) even if (D) in case**
   → **B** (provided that = on condition that)

5. If the marketing budget _______ larger, we would have launched the campaign in Q1.
   **(A) were (B) had been (C) is (D) will be**
   → **B** (Third conditional: if + Past Perfect → เหตุการณ์อดีตที่ไม่ได้เกิด)
