## เฉลยและคำอธิบาย

### ข้อ 1 — ✅ (A) reaches

**Zero Conditional** — When/If + Simple Present, Simple Present

กฎหรือระบบอัตโนมัติที่เป็นจริงเสมอ ใช้ Simple Present ทั้งสอง clause
"will reach" และ "would reach" ผิดเพราะ zero conditional ไม่ใช้ modal verb ใน if-clause

→ [[Grammar/Rules/04-Conditionals#zero-conditional]]

---

### ข้อ 2 — ✅ (C) reaches

**First Conditional** — If + Simple Present, will + V

Result clause "will proceed" ชี้ว่าเป็น first conditional → if-clause ต้องใช้ Simple Present
"will reach" ผิดเพราะ if-clause ห้ามใช้ will (Common Mistake ที่ออกใน TOEIC บ่อย)

→ [[Grammar/Rules/04-Conditionals#first-conditional]]

---

### ข้อ 3 — ✅ (D) were

**Second Conditional** — If + were, would + V

สมมติสถานการณ์ที่ไม่เป็นจริงในปัจจุบัน ใช้ "were" สำหรับทุก subject ใน formal/TOEIC writing
"was" ผิดเพราะ TOEIC ใช้ formal grammar → ต้องเป็น "were"
"had been" ผิดเพราะจะเปลี่ยนเป็น Third Conditional แต่ result clause เป็น "would be" (ไม่มี have)

→ [[Grammar/Rules/04-Conditionals#second-conditional]]

---

### ข้อ 4 — ✅ (D) had identified

**Third Conditional** — If + Past Perfect, would have + V3

Result clause "would not have been necessary" ชี้ว่าต้องใช้ Past Perfect ใน if-clause
"would have identified" ผิดเพราะ if-clause ห้ามใช้ would have (Common Mistake ที่ออกใน TOEIC)
"identified" (Past Simple) ผิดเพราะไม่ match กับ "would have" ใน result clause

→ [[Grammar/Rules/04-Conditionals#third-conditional]]

---

### ข้อ 5 — ✅ (C) had invested

**Mixed Conditional Type 1** — If + Past Perfect (อดีต) → would + V base (ผลในปัจจุบัน)

"a decade ago" = อดีต → if-clause ใช้ Past Perfect
"would be the market leader today" = ผลในปัจจุบัน → result clause ใช้ would + V base (ไม่มี have)
"invested" ผิดเพราะ if + Past Simple + would = Second Conditional (ปัจจุบัน ไม่ใช่อดีต)

→ [[Grammar/Rules/04-Conditionals#mixed-conditionals]]

---

### ข้อ 6 — ✅ (C) were

**Mixed Conditional Type 2** — If + were/Simple Past (สถานะปัจจุบัน) → would have + V3 (ผลในอดีต)

architect ยังขาดประสบการณ์อยู่ตอนนี้ (ปัจจุบัน) → ทำให้ผ่านข้อผิดพลาดในโปรเจกต์ที่ผ่านมาไปไม่ได้
"had been" ผิดเพราะจะกลายเป็น Third Conditional ทั้งคู่ (อดีต + อดีต) ซึ่งเปลี่ยนความหมาย

→ [[Grammar/Rules/04-Conditionals#mixed-conditionals]]

---

### ข้อ 7 — ✅ (D) unless

**Conjunction: unless** = if...not (ยกเว้นว่า)

"will not be scheduled unless all heads submit" = "will not be scheduled if all heads do not submit"
"even if" ผิดเพราะหมายความว่า "ถึงแม้ว่า" (เงื่อนไขไม่เปลี่ยนผล)
"in case" ผิดเพราะหมายความว่า "เผื่อว่า" ไม่ใช่เงื่อนไขปฏิเสธ
⚠️ จำ: unless ไม่ใช้ not ซ้ำ → "unless they do not submit" คือผิด

→ [[Grammar/Rules/04-Conditionals#conditional-conjunctions]]

---

### ข้อ 8 — ✅ (D) as long as

**Conjunction: as long as** = ตราบใดที่ (เน้นเงื่อนไขที่ต้องคงอยู่ตลอด)

"consistently met" = เงื่อนไขต่อเนื่อง → ใช้ "as long as" ได้เหมาะที่สุด
"in case" = เผื่อว่า (เตรียมรับมือ) / "unless" = ถ้าไม่ / "even if" = ถึงแม้ว่า — ล้วนเปลี่ยนความหมาย

→ [[Grammar/Rules/04-Conditionals#conditional-conjunctions]]

---

### ข้อ 9 — ✅ (C) Should

**Inverted Conditional** — Should + S + V base = If + S + should + V (formal)

"Should any discrepancies be found" = "If any discrepancies should be found"
ใช้ใน business notices/official documents เพื่อ formal tone
"Were" ผิดเพราะต้องใช้รูป "Were + S + to + V" ไม่ใช่ "Were...be found"
"Had" ผิดเพราะต้องใช้ "Had...been found" (Past Participle) และความหมายจะเป็นอดีต ขัดแย้งกับ "will be notified"

→ [[Grammar/Rules/04-Conditionals#inverted-conditionals]]

---

### ข้อ 10 — ✅ (D) had conducted

**Wish + Past Perfect** = เสียใจกับสิ่งที่ไม่ได้ทำในอดีต

การ launch เกิดขึ้นไปแล้ว → เสียใจว่าไม่ได้ทำ research ก่อน → wish + Past Perfect
"conducted" (Past Simple) ผิดเพราะ wish + Past Simple = ปรารถนาให้ปัจจุบันต่างออกไป
"would conduct" ผิดเพราะ wish + would = อยากให้คนอื่นเปลี่ยนพฤติกรรม ไม่ใช่แสดงความเสียใจ

→ [[Grammar/Rules/04-Conditionals#wish--if-only--would-rather]]
