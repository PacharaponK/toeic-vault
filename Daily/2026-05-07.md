### Part 5 — Conditionals (ผิด 4/10)

**ข้อ 3 — Second Conditional: was vs were**
- เลือก `(B) was` → ถูกคือ `(D) were`
- กฎ: Second Conditional ใช้ `were` กับทุก subject ใน formal writing (TOEIC)
- → [[Grammar/Rules/04-Conditionals#second-conditional]]

**ข้อ 5 — Mixed Conditional Type 1: invested vs had invested**
- เลือก `(A) invested` (Simple Past) → ถูกคือ `(C) had invested` (Past Perfect)
- กฎ: "a decade ago" = อดีต + result clause "would be...today" = ปัจจุบัน → ต้องใช้ Past Perfect ใน if-clause (ไม่ใช่ Simple Past ซึ่งเป็น Second Conditional)
- → [[Grammar/Rules/04-Conditionals#mixed-conditionals]]

**ข้อ 6 — Mixed Conditional Type 2: had been vs were**
- เลือก `(B) had been` (Past Perfect) → ถูกคือ `(C) were` (Simple Past/were)
- กฎ: result clause "would have been caught" = อดีต → if-clause ต้องเป็นสถานะปัจจุบัน (`were`) ไม่ใช่อดีต (`had been`)
- สัญญาณ: ถ้า result = `would have + V3` แต่ if-clause พูดถึงสถานะปัจจุบัน → ใช้ `were/Simple Past`
- → [[Grammar/Rules/04-Conditionals#mixed-conditionals]]

**ข้อ 8 — Conjunction: in case vs as long as**
- เลือก `(A) in case` → ถูกคือ `(D) as long as`
- กฎ: `in case` = เผื่อว่า (เตรียมรับมือสิ่งที่อาจเกิด) / `as long as` = ตราบใดที่ (เงื่อนไขต่อเนื่อง)
- "consistently met" บ่งชี้เงื่อนไขต่อเนื่อง → `as long as`
- → [[Grammar/Rules/04-Conditionals#conditional-conjunctions]]

### สรุปจุดอ่อนหลักของวันนี้

**1. Mixed Conditionals — ยังสับสน Type 1 vs Type 2**
- **Type 1** (อดีต → ปัจจุบัน): `If + Past Perfect, would + V base`
  - ดู signal: if-clause มีเวลาอดีต (ago, last year) + result มี "now / today"
- **Type 2** (ปัจจุบัน → อดีต): `If + were/Simple Past, would have + V3`
  - วิธีจำ: ดู result clause ก่อน — ถ้าเห็น `would have + V3` → if-clause ต้องเป็นสถานะปัจจุบัน (`were`) ไม่ใช่ Past Perfect

**2. Were สำหรับทุก Subject — ใน if-clause และ wish**
- Second Conditional: `If I/he/she/it **were**...` (ห้ามใช้ was ใน TOEIC)
- Wish: `I wish he **were**...` / `She wishes it **were**...`
- If Only: `If only the budget **were** larger`

### Part 6 — Tenses (ผิด 1/4)

**ข้อ 131 — Present Perfect vs Present Continuous**
- เลือก `(D) are introducing` → ถูกคือ `(B) have introduced`
- กฎ: portal พัฒนาเสร็จแล้วและผลยังมีอยู่ (portal พร้อมใช้งาน) → Present Perfect
- `are introducing` = ยังอยู่ระหว่างดำเนินการ (ไม่ตรงกับ "Starting June 1, all clients must use this platform")
- → [[Grammar/Rules/01-Tenses#present-perfect-vs-simple-past]]
